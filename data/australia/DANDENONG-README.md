# 丹德农保卫战（1943年9月12日，架空）

地图：88×68，5984个格子；工事70、雷区12；单位84。

地理设计：丹德农城区位于西南平地，丹德农山脉位于北部及东部。包含贝尔格雷夫、厄普韦、奥林达、萨萨弗拉斯、埃默拉尔德、贝里克等节点。此图为**游戏化示意地形**，不是实测高程或精准GIS。

防守反击：澳军以山脊堡垒、碉堡、堑壕和雷区建立纵深阵地，机动预备队在道路节点待机；日军从西南和南部集结，争夺丹德农、贝尔格雷夫、贝里克三个目标。

胜利条件：30回合防守三处核心目标，或消灭对方部队。反击由玩家主动操作，当前未额外修改战斗引擎。
